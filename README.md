# 🚀 Event Coming Soon Page

## 🌍 Live Demo
https://abdullahdigital.github.io/comingsoon/

## 📌 Overview
This project is a sleek and engaging "Coming Soon" landing page designed to build anticipation for an upcoming event or website launch. Featuring a dynamic countdown timer and an eye-catching rocket animation, it provides a captivating user experience while keeping visitors informed about the launch progress.

## ✨ Features
*   **Dynamic Countdown Timer:** Displays real-time countdown to the launch date, creating excitement and urgency.
*   **Engaging Rocket Animation:** A visually appealing rocket animation adds a touch of dynamism and reinforces the theme of launch.
*   **Responsive Design:** Optimized for various screen sizes using Bootstrap and custom media queries, ensuring a seamless experience on desktops, tablets, and mobile devices.
*   **Social Media Integration:** Easy access to social media profiles (Facebook, Instagram, LinkedIn) to connect with the audience.
*   **Image Preloader:** A subtle preloader ensures a smooth loading experience for the page content.
*   **Interactive Image Enlargement:** Clickable logo that enlarges for better viewing, enhancing user interaction.

## 🛠️ Tech Stack
*   **HTML5:** For structuring the web content.
*   **CSS3:** For styling, including custom animations and responsive design.
*   **JavaScript:** For dynamic elements like the countdown timer and image enlargement functionality.
*   **Bootstrap 5:** A powerful front-end framework for responsive and modern UI components.
*   **Font Awesome:** For scalable vector icons.

## 🚀 Getting Started
To get a copy of this project up and running on your local machine for development and testing purposes, follow these simple steps.

*   **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/event-coming-soon.git
    ```
*   **Navigate to the project directory:**
    ```bash
    cd event-coming-soon
    ```
*   **Open `index.html`:**
    Simply open the `index.html` file in your preferred web browser to view the project.

## 📂 Project Structure
